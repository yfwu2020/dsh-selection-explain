A · 分段开关「文字 ｜ 网页」推荐

把两个格式并排摆出来，当前项高亮——"在两种输出格式之间切换"这件事没有第二种解读。也顺手教会用户：关掉就是文字。

文字网页
✓ 无歧义：两种格式都在眼前，当前的一目了然
✗ 比现状略宽（约 100px），但行内左侧空间充足
✓ 一次点击即切换，不用展开菜单
✗ 语义是"二选一"，不是"开关"——但实际行为就是二选一

B · 真开关「网页回答 ◯—」

用标准的开关样式（轨道 + 滑块）表达布尔量，左侧文字说明它管的是什么。语义 = "让回答变成网页"。

网页回答
✓ "开关"这个性质最清楚（轨道+滑块是通用语言）
✗ "网页回答"仍不是一个纯格式名词，关掉后是什么没写出来
✓ 宽度适中（约 96px）
✗ 小尺寸下开关轨道容易显得琐碎

C · 当前值胶囊 + 菜单「格式：文字 ▾」

只显示当前格式，点开才是菜单。最省空间，且能用副标题解释每一项。

✓ 菜单里能写清两种格式的差别（教学成本最低）
✗ 面板窄，弹出菜单可能被裁

D · 图标分段「¶ ｜ </>」

用最通用的两个符号代表"文本"与"代码/页面"，靠 hover 提示补语义。最紧凑。

E · 双态文字胶囊「输出 · 文字 ⇄ 输出 · 网页」

一个胶囊，文字直接写清"输出什么"，点一下就翻面。不带图标、不带菜单。

我的建议：A（分段「文字｜网页」）——把两个格式并排摆出来，当前项高亮，"这是输出格式的开关"没有第二种解读， 而且能顺手告诉用户"关掉就是文字"。若你更想要"开关"的心理模型，就选 B；若面板更挤、宁可多一次点击，选 C（"格式：…" 三字最直白）。
