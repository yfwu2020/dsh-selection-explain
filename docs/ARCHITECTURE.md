划词解读由 DSH 宿主服务、浏览器界面和 macOS 原生探针组成。

## 装配与状态

宿主入口只负责公开 DSH 需要的 `name`、`inject`、`Config`、`apply`。`apply` 创建各服务工厂，再注册原有 `/selection-explain/api/*` 路由。服务通过参数接收 `ctx`、配置和所需的其他服务。配置对象在实例内共享，设置更新立即对后续请求生效；模型缓存、历史和会话缓存由对应服务持有。

浏览器入口调用 `view.js` 创建 DOM，通过 `controllers.js` 向控制器传递节点、回调和必要的状态访问器。可变状态通过访问器读取当前值，避免复制布尔状态或模型缓存造成界面不同步。控制器之间的连接集中在装配层；依赖类型由 `controller-contracts.d.ts` 检查。偏好、面板状态和胶囊交互状态分别由工厂创建，每次挂载拥有独立实例。`events.js` 返回统一的清理函数。纯渲染、音频编码、图标和预览桥使用普通模块导出。

`analyze.ts` 负责 HTTP 验证与阶段调度，执行上下文以明确类型传递给消息、工具、流式轮次和补结论模块，继续使用原有取消信号和容量限制。截图服务由每次宿主 `apply` 创建，持有自己的任务、长轮询和临时目录。平台接口可注入，几何规则不访问系统；任务结束会取消未使用的预读取，停用会中止活动命令、释放等待客户端并在命令退出后清理文件。

客户端通过 esbuild 打包为一个 CommonJS 工厂，并由 `window.__ModuleLoader__.load` 注册。模块求值发生在工厂 materialize 时，DOM 挂载和监听仍由 `apply` 执行；停用时通过已有 effect/slot 清理资源。

客户端结果缓存由 `memory.js` 管理：最多 20 项，序列化文本的 UTF-16 估算总量最多 8 MiB，读取命中会刷新淘汰顺序。缓存保存独立 JSON 快照，避免保留可变界面对象；此预算不代表浏览器进程的堆内存上限。计时器作用域只登记仍然活动的计时器，完成、取消和卸载时立即移除。

长对话默认渲染最近 40 条可见消息，按需每次再展开 40 条；完整轮次仍用于保存与组装模型请求。关闭面板会清除回答区域的 DOM 和预览帧登记，保留文字、草稿与待发送附件，重开时重新渲染。卸载时还会释放附件 object URL、缓存、计时器和桥的帧引用。

## 小窗模型上下文

`src/chat-context.ts` 是浏览器/宿主共享的纯协议：包含输入估算、容量预留、完整问答分界、原文指纹及版本1进度。`contextState` 随历史记录保存，字段为 sessionId、source、through、digest、summary 和 background。指纹只用于检测原文变化，不是权限凭据。初次追问冻结会话绑定与背景，跨主会话重开仍恢复原绑定；客户端恢复进度前验证前缀指纹，只映射并发送未压缩的原文尾部，不再随消息变旧把HTML改写成Markdown。隐藏解读前情作为固定背景单独发送，不计入持久消息偏移。旧历史没有进度时按完整历史处理。

`host/chat-context.ts` 优先读取宿主模型容量和视觉计价能力，兼容缺少这两个接口的旧宿主；默认输入预算200000估算tokens。文本按ASCII每3字符、其他UTF-16单元每1字符估算一个token，再预留安全余量；这不等于供应商的精确计数。图片缺少计价接口时按每512×512像素约1024 tokens保守估算，最少计1024，避免把小缩略图计作整张百万像素图片。模型容量已知时扣除输出和工具预留。达到输入预算85%时，将较早完整问答按批次调用同一路由生成摘要，并优先保留最近一组问答；如果最近一组也无法在预算内原样保留，则允许把它一并摘要（未回答的历史提问不会被单独吞掉）；摘要成功且重新估算合格后才发送新的SSE进度。不能安全容纳当前材料或摘要失败时明确报错，不推进进度。被拒绝的本轮用户/助手消息以contextExcluded标记保留原文，模型请求只投影短占位，消息编号不变，后续短问题不会被失败输入堵住。主工具循环与补结论请求都对实际消息（包括嵌套工具结果和图片）再次检查容量；补结论保留摘要、原文尾部及已恢复图像。

附件重建不再按固定图片张数、字节或文件数滚动替换历史。小窗独有的 `selection_material` 工具随全局工具开关和轮数开关启用：用附件ID在本次传入的规范化索引中查找，由宿主附件服务验证路径及存在性；旧图以新的材料消息提供，旧文件返回只读路径。工具只接受已列出的ID或已压缩的消息编号，不接受任意磁盘路径。恢复的附件通过SSE关联到当前用户消息，下轮仍保持稳定。原始消息从已保存的本小窗历史按字符分页读取；关闭保存或历史被删除时明确报告原文不可用。摘要中的路径不能授予读取权限。

压缩进度和附件索引都不是图片/文件字节副本，也不新增跨会话的无界内存缓存。HTTP请求体及历史保存仍有大小护栏；客户端在共享的512KiB请求体边界前本地拒绝过大输入，并保留原文及可恢复状态；历史保存仍有2MB护栏，失败时在回答旁明确提示复制重要内容。摘要不能代替原始记录。

## 数据和发布资源

用户数据位于 `${DSH_HOME}/selection-explain`，未设置 `DSH_HOME` 时使用 `~/.dsh/selection-explain`。本次整理保留各 JSON 文件格式和 HTTP 路径。

发布内容仅包含 `lib/`、原生探针源码、装配清单、运行时 skill、README 和许可证。Linux 构建不会产生 macOS 二进制；Mac 上首次使用可按源码 hash 在数据目录中编译并缓存。因此 `native/mic-probe.c` 和 `native/window-list.c` 都必须保留。窗口探针优先使用包内二进制；缺失时编译到唯一临时路径，成功后替换缓存，失败时保留截图降级路径。宿主文件移动后的资源路径相对于 `lib/host/` 解析。

README 截图使用仓库中的版本链接，不随运行时包复制。`assets/` 仍在仓库中。公开架构和贡献说明纳入版本控制，其余本机资料与设计实验继续忽略。
