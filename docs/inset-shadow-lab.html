inset box-shadow 实验室 · 「日月轮回」能不能借

原效果出自你给的 toggle-ui-vol2.html 第 09 卡。所有控件都能点、滑块能拖，边拖边看。
「日月轮回」里其实用了 两处完全不同的 inset，价值不一样：
① 轨道的内阴影 box-shadow: inset 0 0 26px rgba(0,0,0,.28) —— 让药丸看起来是一个有厚度的天空（四周压暗）。
② 球体的内阴影 box-shadow: inset -9px -3px 0 0 rgba(20,26,58,.92) —— 用一枚带位移、零模糊的内阴影，从右下"咬掉"一块 → 同一个圆，太阳变月牙。不用遮罩、不用第二个元素、不换 SVG。
第 ② 个是这个设计真正的巧思，第 ① 个是任何尺寸都能用的"体积感"技巧。下面分别验。

一、原样复刻（126×66）　点它试试，再看浅色舞台上是否成立

日 → 月：球体 translateX(60px) + 换渐变 + 加上那枚位移内阴影；光芒 scale(.4) rotate(60deg) 收束淡出；云淡出平移；星星延迟浮现。 月球上那枚 0 模糊、0 扩散的内阴影是关键 —— 模糊一加，月牙就糊成"底部渐暗"，没有"缺一块"的锐利感。

五、结论：能不能借

技法原用法可迁移性判断
位移 + 0 模糊的内阴影
（咬出月牙）		 48px 球 → 太阳变月牙 任何"圆 → 缺一块"的图形；**尺寸下限约 24px**，16px 只剩暗边 看尺寸　我们的控件里没有 24px 以上的圆，不适合直接搬
大模糊的内阴影
（四周压暗）		 轨道 inset 0 0 26px rgba(0,0,0,.28) 任何尺寸都成立；给容器"体积感 / 凹陷感" 可借　正是分段控件轨道缺的那点厚度（借法 A/B）
方向性内阴影（上暗下亮） （原设计未用，同一族） 模拟"上光源"的标准做法：inset 0 1px 2px rgba(0,0,0,.5) + inset 0 -1px 0 rgba(255,255,255,.06) 可借　比大模糊更"干净"，浅色主题下尤其明显
整套叙事（光芒 / 云 / 星） 一次切换演完一次天象 要 100px 以上的画布与 0.8s 时长 不借　我们的控件 26px 高，装不下叙事，也会拖慢节奏
结论一句话：能借，但要借对那一半 —— 「日月」真正值钱的是位移内阴影咬形状和内阴影做体积这两种技法， 而不是那套天象叙事。
对我们最有用的落地：借法 A / B —— 给「输出偏好」的分段轨道加一层方向性内阴影（凹槽感）， 尺寸无关、成本极低（一行 box-shadow），而且和"二选一"的语义完全兼容；
不建议：把日月整套塞进来（尺寸不够 + 又把语义拉回开关），也别在 16–24px 的图形上指望月牙能看清。
照旧：插件代码没动，你看完告诉我借法 A 还是 B（或都不借）。
