「网页」图标候选 · 全部画出来

每个图标都放在三种尺寸下看：44px（看清细节）、15px 圆形按钮（关/开两态，真实控件）、14px（真实图标大小）。24×24 视图框、1.6 描边，和插件现在的图标同一套画法。
为什么会挑不出一个"完美表示网页"的图标：14px 下只能容纳 2–3 个笔画。所以判断标准很硬—— 这个图形缩到 14px 还剩几个可辨认的笔画？下面 可读性 一列就是这个判断：强 = 缩到 14px 依然认得出， 中 = 勉强，弱 = 糊成一团。

结论：真正"表示网页"的图标只有三族——窗口（①②③⑧⑪）、地球（④⑤）、地址栏（⑩）； 其余（⑥⑦文档、⑨卡片、⑫外链）在通用图标语言里都另有含义，用在"网页输出"上会误导。
14px 能活下来的只有 ① 浏览器窗口（2 笔）与 ② 极简窗口；想要"排版感"就 ⑧；想保留"网络"含义就 ⑤ 简化地球。
我的建议：① + 「讲透」 —— 图标说"会给你一个网页"，文字说"讲到你懂"，两者不重复、互相补足。
