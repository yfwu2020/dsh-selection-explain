不改变底色 · 日与月只靠球体与图标区分

轨道底色在两档之间保持不变（不再白天/夜晚切换），只有球体滑动、球体外观与图标变化。四种固定底色各画一遍，两态并排 + 一个可点的。
先说一个必然的后果：原设计里"天空变暗"承担了一半语义 —— 底色一旦固定，"日 / 月"就失去上下文， 退化成暖球 / 冷球，档位只能靠图标来说明。
另外：固定浅底时，那颗浅灰的"月亮"和底色对比很弱（要补一圈分离阴影）；固定深底时，暖色的"太阳"反而是全场最亮的点。

结论：底色固定之后，"日 / 月"就只剩装饰性 —— 真正在说明档位的是图标（M↓ / ▭）。所以：
  • 想要"融入界面、两档都清楚" → 控件凹槽底（中性）+ 日月球，尺寸 92×48 或 64×34；
  • 想要"最克制、只靠图标" → 凹槽底 + 中性白球（这其实就等于我们现在的分段控件，多了一层滑动动画）；
  • 想要"最有戏" → 那就别固定底色，回到上一版的天空跟着变（日→月＋天空变暗一起演）。
